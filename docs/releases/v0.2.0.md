# Vexaura v0.2.0 — System & Root

The first Android milestone of **Vexaura** introduces a separate app identity and an advanced System & Root settings page that follows the existing Liquid Glass interface.

### New features
- Native **Settings → System & Root** page using the standard Vexaura settings components.
- Actual **UID 0 authorization** check via the user's own root manager, reporting granted, denied, missing and timeout states.
- Optional **Xposed/LSPosed integration** with in-app activation detection. Users choose module scopes in their own Xposed manager.
- **Sound Settings:** live Android BassBoost and digital session-gain sliders, distinct from a multiband equalizer, applied to Vexaura's playback session.
- **Audio quality:** wired to the existing Wi-Fi/cellular source-quality, PCM/float, bit-perfect, USB-DAC and spatial-audio features.
- **Widget hub:** Android launcher pin requests for the existing Compact, Wide and Capsule playback widgets.
- **Samsung:** experimental media Now Bar color hook for compatible One UI versions, with a status check and disabled options on non-Samsung phones.
- All previously implemented **OLED and animated cloud styles** and the shared **Liquid Glass navigation island** remain available.
- Separate Android application identifier: \`ctrl.mietze.vexaura\`.
- The built-in update checker targets Vexaura's own GitHub Releases.

### Compatibility and limitations
Root, Xposed and Samsung Now Bar modifications require the actual device's support and user-granted permissions. An active module in the app does not prove Samsung SystemUI has loaded the hook. Samsung/OEM internal classes can change between One UI releases.

BassBoost and LoudnessEnhancer modify Vexaura's digital playback path; **they cannot guarantee exceeding the device's hardware audio limits**. Effects are bypassed for bit-perfect audio. They do not overwrite system files, alter other apps' audio streams or grant system UID 1000.

This is an early release; the Samsung hook is experimental. For implementation details, see the [System & Root documentation](https://github.com/ctrl-mietze/Vexaura/blob/main/docs/SYSTEM_ROOT.md).

The Android APK is signed with the permanent Vexaura release certificate; signing details remain private.
