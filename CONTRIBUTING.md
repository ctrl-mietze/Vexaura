# Contributing to Vexaura

Vexaura is in its foundation phase. Open an issue before proposing major architectural changes.

- Keep pull requests focused and testable.
- Describe affected devices, Android versions and reproduction steps.
- Do not commit credentials, signing materials or compiled release packages.
- Keep core playback independent of optional privileged services.
- Preserve source-level copyright and license notices.
- Design privileged operations around explicit consent, narrow capabilities and safe fallback.
