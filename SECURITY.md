# Security

Vexaura is an early-development project. Its planned root, shell and system-UID integrations have not been implemented or audited as Vexaura features.

Do not disclose exploitable findings or sensitive logs in public GitHub Issues. Please contact the maintainer privately, or use GitHub private vulnerability reporting if enabled.

Future privileged services should require explicit authorization, verified callers, narrow capabilities, authenticated IPC and a safe unprivileged fallback.
